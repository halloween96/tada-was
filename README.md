프로젝트 개요
TADA는 사용자가 일기를 기록하고 AI 기능을 활용할 수 있는 서비스입니다.
이 프로젝트에서 백엔드의 검색 기능을 담당했으며, 사용자가 일기에 작성한 단어를 정확히 기억하지 못하더라도 자연어 검색을 통해 의미상 관련 있는 일기를 조회할 수 있도록 구현했습니다.
검색어와 일기 본문을 임베딩 벡터로 변환하고, PostgreSQL의 pgvector를 이용해 코사인 거리 기반으로 유사한 일기를 검색하도록 구성했습니다.

주요 구현
1. Voyage AI를 활용한 자연어 검색
사용자가 입력한 검색어를 `VoyageAIEmbeddingService`에서 Voyage AI API에 전달해 1024차원 임베딩 벡터로 변환하도록 구현했습니다.
변환된 벡터는 `SearchRepository`의 검색 쿼리에 전달하고, PostgreSQL pgvector의 코사인 거리 연산자(`<=>`)를 활용해 저장된 일기 임베딩과 비교했습니다. 이를 통해 검색어와 일기 본문에 같은 단어가 없어도 의미상 가까운 내용을 검색할 수 있도록 구성했습니다.
검색 대상은 `ACTIVE` 상태이며 임베딩이 존재하는 일기로 제한하고, 코사인 거리 기준값 `0.7` 미만인 결과를 조회하도록 구현했습니다. 이 값은 거리 기준이며 검색 정확도 70%를 뜻하지 않습니다.
2. 검색 API 및 사용자별 검색 제한
`SearchController`에서 `GET /api/search` 요청을 받아 검색어, 페이지, 정렬 조건을 처리하도록 구현했습니다.
Spring Security의 인증 정보에서 로그인 사용자 UUID를 추출하고, Repository 검색 조건에도 해당 사용자 ID를 적용하여 다른 사용자의 일기가 검색되지 않도록 했습니다.
검색 결과는 일기 엔티티를 직접 반환하는 대신 `SearchResultResponse` DTO로 변환하여 필요한 정보만 응답하도록 구현했습니다.
3. 검색 결과 정렬 및 페이지네이션
검색 결과를 사용자가 원하는 기준으로 확인할 수 있도록 `latest`, `oldest`, `relevance` 세 가지 정렬 옵션을 구현했습니다.
`latest`: 일기 작성 날짜 최신순 (기본값)
`oldest`: 일기 작성 날짜 오래된순
`relevance`: 검색어와 코사인 거리가 가까운 순
Spring Data의 `Pageable`을 활용하여 페이지 단위로 결과를 조회하도록 했으며, 기본 페이지 번호는 `0`, 페이지 크기는 `3`으로 설정했습니다.
4. 일기 생성·수정에 따른 임베딩 갱신
일기가 새로 작성되거나 수정되었을 때 검색에 사용되는 임베딩도 갱신되도록 `DiaryEmbeddingEventListener`를 구현했습니다.
`@TransactionalEventListener`를 통해 일기 저장 트랜잭션 커밋 이후 이벤트를 수신하고, `@Async`로 임베딩 생성을 비동기 처리하도록 구성했습니다. 생성된 벡터는 Repository의 UPDATE 쿼리를 통해 DB에 저장하도록 했습니다.
5. 외부 API 오류 및 기존 데이터 처리
외부 임베딩 API 호출 시 요청 제한(HTTP 429)이 발생하는 경우 2초 대기 후 최대 1회 재시도하도록 구현했습니다. 검색어가 비어 있으면 외부 API를 호출하기 전에 검증하고, 임베딩 생성이 실패한 경우 검색 서비스에서 오류를 반환하도록 처리했습니다.
또한 개발 환경에서 기존 일기 중 임베딩이 없는 데이터를 순차적으로 보완하는 `DiaryEmbeddingBackfillRunner`를 구현했습니다. 해당 초기화 로직은 `@Profile("!prod")`로 운영 환경에서 실행되지 않도록 구성했습니다.

검색 기능 처리 흐름
```text
사용자 자연어 검색 요청
        ↓
GET /api/search
        ↓
SearchController
(인증 사용자 정보 · 검색 조건 처리)
        ↓
SearchService
(검색어 검증 · 결과 변환)
        ↓
VoyageAIEmbeddingService
(검색어 → 1024차원 임베딩)
        ↓
SearchRepository
(pgvector 코사인 거리 기반 검색)
        ↓
검색 결과 DTO 반환
```
검색 API
```http
GET /api/search?query=기분%20좋은%20날&page=0&size=3&sort=relevance
```
파라미터	설명	기본값
`query`	자연어 검색어 (필수)	-
`page`	조회 페이지 번호	`0`
`size`	페이지당 결과 수	`3`
`sort`	`latest`, `oldest`, `relevance`	`latest`
